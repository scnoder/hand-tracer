# Hand Tracker
It is a real-time hand tracking software that uses Mediapipe and OpenCV. The both index fingers are set to be tracked.
An image of the locations can be found here.
<img width="1170" height="398" alt="image" src="https://github.com/user-attachments/assets/823454f9-1a18-43e8-a1df-b99b17072daa" />



## Requirements
- Python 3 and later versions
- Mediapipe
- OpenCV
- `hand_landmarker.task` file found [here](https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/1/hand_landmarker.task)

## Installation
All dependencies can be installed using `pip install -r requirements.txt`

## Usage
`python tracing.py`

Press 'q' to quit
